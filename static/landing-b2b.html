// Data catalog

Six datasets.
One API key.

All data originates from App's own consumer product — scraped, structured, and continuously refreshed. Not sourced from third parties.

01
GET /prices
Price history
Full timestamped price change log per service, per plan, per country. Goes back 18 months. Includes before/after delta, date of change, and plan-level breakdowns.
CORE DATASET
02
GET /cancel-scores
Cancel difficulty index
Each service scored 1–10 for cancellation difficulty. Breakdown by dark pattern type: confirm-shaming, forced continuity, roach motel, hidden cancel, fake countdown.
UNIQUE DATA
03
POST /webhooks
Price change webhooks
Register a URL and receive real-time pushes the moment any tracked service changes pricing. Subscribe to specific services, categories, or country markets.
REAL-TIME
04
GET /signals
Consumer behavior signals
Anonymized, aggregated data from B2C users. Which price points trigger cancellations, co-subscription patterns, churn triggers by category. GDPR-clean — no PII, no individual data.
ANONYMIZED
05
GET /competitors
Competitor mapping
For each service: direct competitors with pricing, feature overlap score, and Switch-Save delta. Same data powering our B2C Switch & Save feature. Updated daily.
LIVE
06
GET /trials
Trial terms database
Trial length, auto-renew behavior, card requirement, trial-chain availability for 500+ services. Monitored for changes — flagged when terms update.
MONITORED

All responses follow a consistent structure. OpenAPI 3.0 spec available to all customers.

FieldTypeEndpointDescription
service_id
string
/prices, /cancel-scores
Canonical slug identifier — e.g. "netflix", "spotify-premium". Consistent across all endpoints.
price_history[]
array
/prices
Timestamped price snapshots. Each object: {price, date, plan, currency, change_delta, change_pct}.
cancel_score
float
/cancel-scores
1.0–10.0 difficulty rating. 10 = near impossible. Updated when cancel flow changes.
dark_patterns[]
string[]
/cancel-scores
Enum: confirm_shaming, forced_continuity, roach_motel, hidden_cancel, fake_countdown, misdirection.

float
/signals
Median price point at which users cancel this service — derived from anonymized B2C usage data.
competitors[]
array
/competitors
Rival services with: name, price_usd, overlap_score (0–1), save_delta. Same engine as Switch & Save.

all

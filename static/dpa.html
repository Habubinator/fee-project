Data Processing Agreement

Last updated: May 2025  ·  Applies to App Data API (data.censored-link.com)
This Data Processing Agreement ("DPA") forms part of the App Data API Terms of Service between App ("Data Processor") and the API client ("Data Controller" or "Client"). It governs the processing of personal data under GDPR (EU) 2016/679 and, where applicable, UK GDPR.

1. Definitions

  • Controller: The API client who determines the purpose of data processing.
  • Processor: App, which processes data on behalf of the Controller.
  • Personal Data: Any information relating to an identified or identifiable natural person.
  • Processing: Any operation performed on personal data, including collection, storage, use, or disclosure.

2. Nature of data processed

App's API outputs are strictly anonymized and aggregated. The data sold to API clients does not constitute personal data under GDPR because:

  • All consumer behavior signals are aggregated across thousands of users. No individual-level data is included.
  • Price history, cancel scores, and dark pattern data are scraped from public pricing pages. No personal data is involved.
  • Competitor mapping and trial terms data are publicly sourced. No personal data is involved.

App is therefore not acting as a Data Processor for the purpose of delivering API outputs. No personal data is transferred to API clients.

3. Data controller obligations

If you use App API data in combination with your own user data, you are acting as a Data Controller for that combined processing. You are responsible for:

  • Ensuring you have a lawful basis for processing your users' data alongside our API outputs.
  • Providing appropriate privacy notices to your users.
  • Complying with GDPR data subject rights requests relating to your own users.

4. App B2C data and B2B signals

App collects personal data from B2C users (email, subscription records) solely to provide the B2C product. A portion of this data is aggregated and anonymized before being made available via the B2B signals endpoint (/v1/signals). This aggregation process:

  • Removes all individual identifiers before aggregation.
  • Applies minimum cohort sizes (no signal reported for fewer than 100 users).
  • Is covered by App's B2C privacy policy and user consent terms.

5. Security measures

App implements the following technical and organizational measures:

  • All API traffic is encrypted via TLS 1.2+.
  • API keys are hashed before storage.
  • Access to production systems is restricted to authorized personnel only.
  • Regular security reviews are conducted.

6. Sub-processors

App uses the following sub-processors in delivering the API service:

  • Cloud hosting provider (VPS/cloud infrastructure)
  • Stripe (payment processing — no personal data from API outputs)
  • Resend / Postmark (transactional email for account notices)

7. Enterprise DPA

Enterprise plan clients requiring a fully executed, countersigned DPA (e.g., for regulatory or procurement purposes) may request one by contacting api@app.censored-link.com. A custom DPA is included in all Enterprise plan agreements.
